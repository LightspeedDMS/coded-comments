# coded-comments: load by task

Paths are relative to this directory. `<host>` is your language's file in `hosts/`: python, typescript_javascript,
shell, go, rust, csharp, java, pascal, c, cpp, plsql, postgresql, tsql, sqlite.

| task | load |
|---|---|
| write comments | `what.md`, `how.md`, `hosts/<host>.yaml` |
| review a diff | `reviewer.md`, `what.md`, `rules/core.yaml`, `grammar.md`, `exemptions.md`, `hosts/<host>.yaml` |
| migrate old comments | `migrate.md`, plus the write files |
| exempt or not | `exemptions.md`, `hosts/<host>.yaml` |
| unsure of placement (optional) | `examples.md` |
