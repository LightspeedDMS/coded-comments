## Code comments (coded-comments)
Before writing your first comment in a session, read `~/.claude/coded-comments/index.md`.
In code and tests, comment only to prevent a mistake or save a search that code, names, types and tests cannot. Each comment is one coded line that replaces prose, never sits beside it: `// ^ hazard removing nonce => replay attacks; test:TestReplayRejected` (`# ^` Python/Shell, `-- ^` SQL). Tags: hazard coupled security invariant external order why see perf todo; `why <choice>, not <rejected>; <reason>`. One operator per clause: `=>` leads to, `=` `!=` `<` `>`; order by before/after; `;` separates facts; anchors `path:symbol` `#123` `doc:x` `test:Name`. No prose docs (docstrings, JSDoc, godoc) except on a library's public API. Exempt: pragmas, licenses, generated markers.
