## Code comments (coded-comments)
Write a comment only if it prevents a mistake or saves a search that code, names, types and tests cannot, as one coded line, never prose: `//^ hazard removing nonce => replay attacks; #123` (`#^` Python/Shell, `--^` SQL). Tags: hazard coupled security invariant external order why (deliberate choice, do not change) see (pointer) perf todo. `=>` leads to; `;` separates facts; `doc:x` doc anchor. Exempt: exported-API docs, pragmas, licenses, generated markers.
To write, review or migrate comments, read `~/.claude/coded-comments/index.md`.
